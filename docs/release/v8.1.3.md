# Skotiq 8.1.3

This update fixes problems found during a full night of imaging with connected equipment.

## End-of-night processing

- A run that encountered an earlier error can now run its configured end-of-night calibration and warm-up when dawn or an obstruction ends imaging and the mount confirms it is parked. Automatic master building waits for calibration to finish.
- An ordinary failure or an operator stop does not start calibration unexpectedly. A failed or unconfirmed park does not qualify for this recovery path.
- Calibration runs are identified separately so their completion does not start another night-end processing pass.

## Manual centering and camera access

- Manual actions wait for the camera's real exposure and download to finish before using the equipment. This also works when Tonight is opened partway through an exposure.
- Native camera acquisition has exclusive ownership through download. A competing capture cannot replace the current exposure or consume its image buffer.
- A disconnected camera or camera error produces an actionable failure instead of leaving a manual action waiting indefinitely.

## Session summary

- The elapsed clock stops at the recorded run end time.
- Finished-session charts and accepted integration totals remain available after the active session closes.
- Automatic calibration preserves the imaging session's summary instead of replacing it with dark and bias counts.

## Failed-solve diagnostics

Failed automatic plate solves retain the original FITS frame with exposure settings, pointing hints, solver information, and a mount-status sample. Evidence is stored under `failed-solves` in the native log directory, limited to eight failures or 256 MiB. Successful solve frames remain temporary.

These diagnostics help distinguish poor sky visibility, trailing, and pointing problems; this release does not establish the cause of the recent post-flip loss of stars.

## Validation

All 413 Tonight tests passed on the final run, along with core lifecycle, calibration and run-record regression tests, native camera ownership and diagnostic retention tests, and targeted static analysis. One centering test failed during an earlier parallel run and passed both independently and in the final lower-concurrency suite. A new full-night hardware run is still needed to validate the changes under the sky.
