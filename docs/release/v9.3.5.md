# Skotiq 9.3.5

Update the imaging host to 9.3.5 first, then update each linked desktop or mobile client. Skotiq requires both ends of a Link connection to run the same release. The desktop and companion apps are build 46.

A small fix on top of 9.3.4.

## Settings

- Tapping a switch's name or description now flips the switch, as well as tapping the switch itself. Before, only the small switch responded, in Settings and in dialogs such as a notification row's editor. A disabled switch still ignores taps, and a screen reader still finds one control per row.

## Not tested

None of this has run on the rig or on a phone; it was checked by tests, including one that opens Settings › Notifications, finds "Target started" listed as not sent, and turns it on.
