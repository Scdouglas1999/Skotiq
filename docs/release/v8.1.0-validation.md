# Release preparation checks

Version metadata is reconciled at 8.1.0+30. Strict CI additionally identified formatting and iterator-style changes, and a startup-reservation test that opened an asynchronous database after its temporary directory had been removed. That test now owns an in-memory database and drains startup work before exercising the reservation.

## Reviewed placeholder-audit additions

The 27 new textual matches were reviewed in their surrounding code before being added to the existing baseline:

- Twelve `.ok()` directory removals occur in test cleanup (Darkroom regression tests, the real-frame harness and registration-preview tests).
- Flat header loading permits absent FITS metadata for an image that was successfully read; pedestal classification handles missing metadata explicitly. Image-read errors still propagate.
- Optional master image-type strings feed pedestal classification. They do not manufacture a matching calibration frame.
- Optional ASTAP, normalization-reference, slew and centering messages affect diagnostics; failure status and propagation are retained.
- Optional flat-path text formats an error after validation fails. The optional spool filename supplies a working-directory name, not calibrated pixels.
- Missing GRIDREF becomes empty and is explicitly rejected along with mismatched coverage provenance.
- Missing sequence metadata uses the existing FrameWatchConfig defaults. An absent exclusion reason contributes no suffix to an assessment log.

These are scoped acknowledgements of existing behavior, not a broad audit exemption. The gate continues to reject other new matches.

## Full CI follow-up

The full run for the published 8.1.0 commit passed Rust tests on Linux and Windows and desktop builds on Linux, macOS and Windows. Its Dart test job found two failures: the older navigation test still expected Flat Wizard to be absent from More, and the advertised endpoint catalog omitted the already registered Science bundle POST and calibration backlog GET routes. The follow-up corrects that expectation and advertises both routes; the two affected suites pass all ten tests locally. These follow-up changes do not alter the published 8.1.0 tag or binaries. Full CI for the follow-up must be evaluated separately.
