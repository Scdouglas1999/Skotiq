# Skotiq 8.0.0 release preparation

The public release notes are [v8.0.0.md](v8.0.0.md). Version 8.0.0 uses build
29 and the stable channel in both application pubspecs and `version.yaml`.

## Included work

The integration includes all changes since published tag `v7.1.0`, including
`feature/night-control`, `arch/a1`, `arch/a2`, `auto/g2` and `auto/g3`, plus
remaining end-of-night filter discovery and native multi-night delivery work.
The [commit inventory](v8.0.0-commits.md) records the complete range.
Synthetic-flat dust correction remains separate work and is not advertised.

## Identity and compatibility

The repository is `Scdouglas1999/Skotiq`. Product names, package names, binaries,
application IDs, documentation and download URLs use Skotiq. Old identifiers
remain only where required to migrate existing data, read legacy files or
preserve update-signing keys. Android requires a new install and re-pairing.
See [the migration note](rebrand-skotiq.md).

The release workflow uses the configured Android keystore and existing update
signing keys. New `SKOTIQ_UPDATE_*` secret names take precedence, with legacy
aliases retained to avoid changing trust identity. Windows executables remain
unsigned; this is documented separately from signed update manifests.

## Packaging

The release workflow builds Windows x64, Linux x64 and Android APKs for
arm64-v8a, armeabi-v7a and x86_64. It attaches checksums, platform update
manifests, license notices and source-commit records. There is no macOS or iOS
release package. A manual workflow run can attach artifacts to the draft;
publication follows validation of the combined source and package results.

## Screenshot and banner provenance

README screenshots were captured on October 22, 2026 from the existing
Windows imaging-laptop GUI, showing connected equipment, recorded imaging
sessions and the NGC 891 L-filter master. The earlier flat-wizard and web
screenshots are not used in the README.

The animated banner is rendered from the app's TrailsMotion timing and
existing mark geometry, palette and Sora wordmark. Regenerate both colorways
with `python3 tools/brand/render.py banner-anim`.

## Validation

The checks are defined in `.github/workflows/ci.yml` and
`.github/workflows/release.yml`. Static analysis, runtime audits, workspace
Dart/Rust tests, platform builds and signed-manifest verification are separate
evidence; two development nights on one rig do not establish universal
hardware compatibility or validate every subsequent source change.
