# Skotiq 9.3.4

Update the imaging host to 9.3.4 first, then update each linked desktop or mobile client. Skotiq requires both ends of a Link connection to run the same release. The desktop and companion apps are build 45.

A second short follow-up to 9.3.2 for the Android app.

## Tonight

- On a phone, the plan line under the run state may take two lines. One line cut "dark in 1 h 12 m" before a run, and the step and frame counts during one, to an ellipsis. A wrap falls between parts, never inside "Ha 180 s".

## Notifications

- "Target started" is no longer a toast by default. It appeared at every target of a run and covered the phone's frame strip, and the run's own screens already show the target. Turn it back on under Settings › Notifications. The slew a run makes was already quiet in 9.3.3.

## Link

- The link details on a phone say how the host is reached: on this network, or over Tailscale from anywhere.

## Demo rig (testing)

- The demo guider's Settings tab says the guider is simulated and has no settings, instead of sending you to Equipment for an external guider.

## Not tested

None of this has run on the rig or on a phone. The Tonight header was checked in rendered 360 and 411 dp layouts and by tests; the rest by tests.
