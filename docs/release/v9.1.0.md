# Skotiq 9.1.0

Update the imaging host to 9.1.0 first, then update each linked desktop or mobile client. Skotiq requires both ends of a Link connection to run the same release. The desktop and companion apps are build 39.

## Live stacking and Darkroom

- Saving an unfiltered master uses the frames collected in the Unfiltered stack, even when another filter is selected. Linked clients can preview, save, stop and reset a specific filter stack.
- A frame rejected before star detection leaves its star count and alignment unreported. The frame log shows which measurements belong to each exposure.
- Restoring a removed light in Darkroom puts it back with its original calibration group, including when several groups use the same filter.
- A failed FITS write preserves the previous frame on disk.

## Sequences and equipment

- Tonight’s Overview shows the operation the sequence is performing. A linked viewer can join a running exposure and see its countdown, the guiding trace and an autofocus sweep already in progress.
- Sequence start, pause and reset follow the run on the imaging host. A second start request leaves the active run and its recorded frames intact. Standalone meridian flips reserve the rig and report their progress on the mount panel.
- The camera heartbeat accounts for image downloads. Recovery can reopen a lost camera, filter wheel or focuser during a run, and reconnect guiding when PHD2 restarts. An OnStep refusal to park or unpark reaches the operator.
- Plans with a timed capture use the actual stop time. Smart Night omits a trailing flip when the capture already fills the observing window. A new catalog installation refreshes tonight’s target suggestions.

## Updates

Interrupted downloads resume when the server accepts the byte range and restart cleanly when it refuses it. A stalled LAN update connection now times out during authentication as well as during transfer.
