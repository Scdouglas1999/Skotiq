# Skotiq 9.0.1

This release fixes what the first rig night on 9.0 turned up, and what a review of the 9.0.0 release found. It also changes how filters are picked for a target, how calibration frames are taken and reused, and where the current cloud figure comes from.

## Update the host first

Update the imaging host to 9.0.1 first, then each linked client. A client links only to a host running the same release, so a 9.0.0 client says which side to update and does not link until both run 9.0.1.

The database moves from schema 70 to 73 when 9.0.1 first opens it. Back up your profile before updating, and do not open the upgraded database with 9.0.0. The update keeps every row. Focus models move from their separate files into the database; each imported file is renamed to `.json.imported`, not deleted.

## Fixes from the rig night

- Calibration darks no longer start while the camera is still cooling or warming to their set-point. Each set-point gets its own master, and a master taken at another temperature is never used to calibrate.
- Center and autofocus frames use the profile's gain and offset, not the gain left over from the last frame.
- Background device discovery no longer probes a camera or serial port while it is in use. On the rig it was interrupting exposures.
- After a meridian flip, recentering stops PHD2 before it moves the mount.
- A looping PHD2 is no longer reported as a lost star. When PHD2 sends no guide pulses, Skotiq says so.
- Smaller fixes: one Moon figure across screens, a flip countdown that runs until the mount arrives, focuser moves that wait for the focuser to arrive, and Go to search off the screen's thread.

## Filters

- Filters follow the target's type. Emission nebulae, supernova remnants and planetary nebulae get a narrowband set the wheel holds (SHO, or HOO). Galaxies, clusters and reflection nebulae get LRGB. For a broadband target with catalogued emission regions, Skotiq offers Ha as an option, only if the wheel has an Ha filter, and the plan stays LRGB.
- The type comes from catalog data. OpenNGC's generic "nebula" entries are now classed as emission or reflection using five published catalogs: Sharpless, RCW, WISE HII, Cederblad and Magakian. NGC 1333, IC 348, Merope and the Iris now plan LRGB. Saved targets read their type from the catalog too.
- Image tonight, the Build sequence recipe, Smart Night and the step editor share one filter picker. It shows the recommended set and the reason for it, the other sets the wheel can image, and your own named sets.
- Every filter in a set gets an equal share of the time by default, so L no longer gets double. Each filter's share can be changed in the recipe, and a saved set keeps its shares.
- With a motorized filter wheel, automatic plans take one frame per filter in turn, so a night cut short still has every filter. "Dither every N" counts frames across all filters. A filter change applies its focus offset but does not start autofocus.

## Calibration

- One floating-point rule calibrates every light frame. The integer rule that clipped faint sky to zero is gone.
- Pedestals follow PixInsight's defaults: none unless more than 0.01% of a frame would clip at zero, and taken out again when frames are integrated. A pedestal stated in an incoming frame is subtracted before calibration.
- A frame that is already calibrated, as its header records, is never calibrated again. Stack & Share was taking bias and darks out twice.
- End-of-night calibration reuses library bias masters (with no age limit) and darks up to the "Keep library darks for" age, 120 days by default. It builds a master from frames already in the library before taking new ones. If nothing needs taking, the mount does not move. "Retake all" ignores the library.
- "Frame kept uncalibrated" shows once per cause, with a banner that states the reason and the frame count.

## Weather

- The current cloud figure comes from the nearest airport report within 40 km, with its station and age shown, or else from the regional forecast model for this quarter hour. Before, it came from a National Weather Service forecast issued hours earlier, and on a clear afternoon showed 62% cloud.
- The hourly forecast uses Open-Meteo's regional model first (HRRR in the US).
- Weather safety reads the same figure as the screens. It now waits for the first forecast instead of parking while the forecast loads, and it is off unless you turn it on.

## Planning

- One altitude floor applies everywhere: the property horizon where one is set, else the minimum altitude, by direction. The planner, the run and every screen use it.
- One target scorer ranks targets for Best tonight, the planetarium and the scheduler step. Best tonight's window bar shows when a target is above the floor, matching its Imageable hours.
- Plan > Targets replaces Plan Projects, Schedule, Analytics Projects and the mosaic list.

## Screens

- Tonight: tapping a frame in the strip opens the full-resolution frame, with zoom and its stars. Imaging, Analytics and the sequencer use the same viewer.
- Darkroom: the main list shows projects, meaning targets with at least 30 minutes and 10 kept subs (both are settings). Everything else is in a folded Other captures group. Frames are grouped automatically; nothing is moved or deleted without you.
- Equipment: the device list shows every device the host knows about (connected, in the profile, or found by the last scan) and says when the last scan ran.
- Framing: the controls sit in four corner groups and no longer overlap at any window size.
- History is the one list of past nights. Analytics has three tabs and one session picker. Equipment, Settings, the Flat wizard, the Sequencer's Saved and Templates, and Best tonight follow the same screen layout. The Darkroom, Imaging and Weather have phone layouts.

## Other fixes

- Backups restore by record identity, so rows never attach to the wrong record. A full restore keeps a safety copy. On a 185 MB database, a merge restore now takes under a minute instead of more than 51.
- A dropped camera reconnects during recovery. Read mode is a profile and step setting. Park never waits on a hung guider.
- Every notification row has a trigger. A failed exposure is reported as failed, and a lost guide star is reported once per episode.
- Releases publish only from a commit on main that passed every CI check.

## What was not tested

- The rig night of November 15 ran an earlier 9.0.1 build. The later changes have not run on the sky: the filter picker and rotation, the weather source, library reuse, the pedestal and double-calibration fixes, the full-resolution viewer, the Darkroom list and the focus-model move.
- These changes were checked on simulators in a sandbox and against copies of real frames and a real database.
- The Windows package is built and tested by CI against simulators. The Dart suites were run on Windows for an earlier 9.0.1 build, not this one.
- No ARM phone was tested.

## Updating to 9.0.1

[Downloads](https://skotiq.com/downloads.html) include Windows x64, Linux x64, and Android APKs for arm64-v8a, armeabi-v7a and x86_64. Keep the complete desktop bundle together when extracting it. Windows packages are unsigned and may show a SmartScreen warning. macOS and iOS packages are not included.
