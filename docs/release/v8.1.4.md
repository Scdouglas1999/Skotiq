# Skotiq 8.1.4

Overview follows the current sequence operation, framing loads more promptly when a survey server is unavailable, and Plan → Tonight spends less time calculating recommendations.

## Overview

The Before you start checklist becomes a live activity panel once the sequence begins. Autofocus shows its V-curve; slews and centering show mount position and centering error; captures show exposure progress, filter, gain, offset and sensor temperature. Guiding, dithering, flips, recovery, pauses and failures have their own states. The separate Equipment summary has been removed from Overview.

The panel uses the shared chart, progress, metric and theme components. Background frame solves do not replace capture progress, and completed operations do not leave their previous state on screen.

## Framing

- Requests start with CDS. If it is slow, Skotiq tries the official CDS mirror after 0.6 seconds and NASA SkyView after two seconds. An explicit failure advances to the next route sooner.
- The first successful response supplies the image. A failed mirror does not discard a primary request that can still succeed.
- The CDS mirror receives the same survey, coordinates, field of view and requested dimensions. The existing NASA fallback keeps its requested resolution.
- Cached images and protection against stale responses from a previously selected target are preserved.

## Tonight recommendations

Shared time and observer calculations are reused across the target catalog. All targets, altitude samples, horizon constraints, rise/set refinement and scoring rules are retained.

In a desktop benchmark, catalog scoring improved from 2.28 seconds to 0.89 seconds with byte-for-byte identical serialized recommendations. On the imaging laptop, the visibility calculation alone improved from 5.85 seconds to 1.61 seconds across 3,716 targets with identical results. These are measured calculation timings, not a guarantee of the total tab loading time on every computer.

## Validation

Focused framing, scoring and astronomy tests passed, including exact-result comparisons and simulated failures of the primary server, mirror and fallback. Static analysis and the behavioral audit passed. The CDS mirror can help with individual server failures; NASA remains the independent route when both CDS servers are unreachable.

The dashboard update passed 445 Tonight tests, including operation transitions, narrow layouts, readiness actions and existing device controls. Targeted static analysis and the changed panel design-token checks passed.
