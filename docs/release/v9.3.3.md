# Skotiq 9.3.3

Update the imaging host to 9.3.3 first, then update each linked desktop or mobile client. Skotiq requires both ends of a Link connection to run the same release. The desktop and companion apps are build 44.

A short follow-up to 9.3.2 for the Android app.

## Sequencer

- On a phone, a live run's pause, stop and skip sit beside the plan's name instead of in a row of their own. That row also repeated the frame count, time and state the progress card shows, and with the status strip under it a 360 dp phone kept little of the plan in view. Undo and redo lead the plan's menu while the run's controls are on the bar. Stop still needs a hold.
- The phone's add and step properties buttons have names a screen reader can read.

## Demo rig (testing)

- Live view and snapshot frames taken on the demo rig leave the phone's frame list when the demo stops. Their files are deleted with it, so the rows pointed at nothing. Frames kept in the captures folder stay.

## Not tested

None of this has run on the rig. The plan row was checked in a rendered 360 dp phone layout and by tests, not on a phone; the demo rig change by tests.
