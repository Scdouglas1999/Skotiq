# Logging

Code in `skotiq_core` and the packages above it logs through `Log` (`packages/skotiq_core/lib/src/utils/logging_service.dart`): `Log.info(message, source: ...)`, `Log.warning`, `Log.error`. The leaf packages (`skotiq_astro`, `skotiq_planetarium`, `skotiq_plugins`, `skotiq_remote_protocol`, `skotiq_updater`) cannot import core, so they log through `package:logging` with a logger named `Logger('skotiq.<Name>')`. `Log` forwards only records whose logger name starts with `skotiq.` to the log file, the Log Viewer and the remote log tail, with `<Name>` as the source; any other name, and a `Logger.detached`, is dropped. Every app `main` calls `Log.listen()` as its first statement, so a record logged before the logging service exists (catalogs opening, network set-up) still reaches `dart:developer`. A worker isolate has no forwarder: log there with `dart:developer`, or send the message back to the main isolate. The architecture audit (`melos run audit:architecture`, rule `leaf-logger`) checks the logger names and the first line of each `main`.
