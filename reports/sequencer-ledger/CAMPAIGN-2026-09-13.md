## How it was built and verified

Seven workstreams, each with a written brief, an implementation agent, an adversarial
review by a separate agent, a fix pass, and an independent rerun of the sequencer suite on
the merged branch before the next wave started. Reviews caught, before merge: stale-run
snapshots reported as current, a build-phase provider write, hover actions missing from the
default density, an ETA column anchored at build time, a group-move algorithm that scattered
runs on same-parent moves, a sticky stack occluding the rows it pointed at, an auto-collapse
shield that Expand-all disabled for the night, and an ETA re-anchor that measured elapsed
time instead of lateness. Per-workstream reports are beside this file.

Live verification in the release bundle through `tools/ui_audit/drive_linux.py` with the
two fixtures now under `tools/ui_audit/fixtures/`: the 36-node two-target night renders in
one screen in Ledger, folds and rollups read as designed, sticky pins and the gutter track
scrolling, all three densities switch, the inspector tabs work, and a one-minute simulator
run showed auto-collapse, running chips on target / loop / folded row with per-member
progress, and every finished container folded at completion.

## Addendum 2 — the on-sky night

The build froze twice within minutes of reaching focus; the owner's Sep 10 build (rolled back
to briefly) froze the same way. Root cause, found from three hung logs and the code: the first
successful plate solve runs the annotation pipeline, which parsed the entire GLADE+ galaxy
catalogue (896 MB on the rig) synchronously on the UI isolate. Fixed in `w13-hotplug-hang`
(region-scoped streaming catalogue queries off-isolate with a cached field, a bucketed star
matcher replacing an O(stars × catalogue) scan, and a per-frame 65.6 MB texture leak in
`image_display.dart`), 35 tests, every suite green; built on the laptop and installed at 21:08
local as commit `9b5bd9fae`. Rule recorded: soak the capture → solve → detect → annotate path on
the simulator with full-size frames before any rig night.
