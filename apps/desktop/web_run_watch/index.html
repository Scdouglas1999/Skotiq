A pairing code is made on the rig and never sent over the network. Ask for one, read it there, and type it in here. It expires after about 5 minutes; just ask again if it does.

A desktop rig shows the code on its Remote Access screen. A headless rig has no screen: it writes the code to an owner-only pairing-code.txt in its Skotiq support folder, and prints it to the console when it was started with --pairing-print-codes.
